# Private Office authentication pilot — 2026-11-28

Isolated from public Office Register, F08 and broker gateway. All displayed data are fixed placeholders; no secrets, accounts, market API or actual portfolio are attached. Access-key verification is a local single-owner pilot, not independent production security certification or A2 approval authority.

Required Railway variables on this service only: OFFICE_ORIGIN (exact generated HTTPS Railway domain), OFFICE_ACCESS_TOKEN (random password-manager generated 32–128 ASCII letters/digits/underscore/hyphen; prefer 48+ characters). Enter the token directly in Railway Variables, seal it, keep it in your password manager; never put it in repository, chat, URL or logs. No default. Missing/malformed config locks all pages and API with 503; /health is liveness only. Rotate by replacing secret and redeploy; all in-memory sessions expire on restart. 30-minute absolute session TTL, max 8 sessions; secure HttpOnly SameSite=Strict host-only cookie; origin-checked POST, no cache, no framing, no client-side credential storage, per-process global 8 login attempts/minute. Rate limit can temporarily deny access; no distributed or persistent throttling. Single replica only. HTTPS edge and host routing must be independently verified. No trusted identity provider, MFA, persistent revocation or external audit yet. No actual financial data until authenticated external smoke test, independent review and private processing/storage permissions. Public preview and PR #141 unchanged. No real credentials in fixtures.
