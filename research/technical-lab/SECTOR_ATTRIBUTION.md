# Sector attribution / relative context (research only)
Scope: secondary analysis of existing frozen events, not new indicator or entry rule. Existing #138 Vault owns storage, #142 user-facing watchlist scope untouched. Do not promote #146 or operate on private investment data.
 
## Inputs / outputs
Use archived audit.json and universe.json from verified research run. Prepare private sector-input.json with universeSha256 (exact file SHA256), asOf (UTC), marketId, calendarEvidence, sessions [{date,closeAt}], mappings, series, contextRequests. Evidence declarations on calendar/mapping/series: status VERIFIED, source, evidenceSha256, rights RESEARCH_ALLOWED. These are external reviewer attestations; program checks shape, NOT truth or authorization independently. Do not put licensed raw data or credentials in Git.
- Mapping: asset (original ledger ticker), securityId (stable ID), sectorId (historical classification), benchmarkId, from inclusive, to exclusive/null, knownAt UTC. Exactly one applicable row known at signal close; missing/conflicting records block. Use independent historical source, not today's sector labels.
- Series: id, kind MARKET/SECTOR, currency USD, basis TOTAL_RETURN_ADJUSTED_PROXY, capturedAt UTC, bars [{date,open,close,knownAt}]. Include complete reference sessions, knownAt no earlier than close and no later than capture. Need independent benchmark source and classification evidence. No implicit extrapolation, FX conversion, dividend double count or interpolation.
- ContextRequests: [{sectorId: benchmark series ID, date, asOf optional}]. 20/60/120-session close-to-close relative return, each period independently blocked on gaps. This is price-relative context, not an economic cycle classifier. No automatic risk score or investment trigger.
- Command: node research/technical-lab/run_sector_attribution.mjs audit.json universe.json sector-input.json <expected-input-sha256> output.json
- Event attribution: existing stock return minus sector return, sector return minus market return, and stock return minus market return. Same next-open to exit-close horizon and .995 factor as frozen study. Original market return must match recomputed benchmark. Exact reference endpoints and complete benchmark window required. No stock interior session or corporate-action certification. Censored stock outcomes remain unknown. Output coverage per original cohort/rule/horizon/hit; incomplete coverage is visible; original reports never overwritten.
