# Vault feature bridge v1 — offline research only
Reuses P0 vault SQLite tables and existing indicators, does not change production FeatureProvider or active market indicators. Strict declared window requires dataset identity, ordered session+close timestamps and explicit calendar/corporate-action references; RAW only in declared action-free window. Latest known revision selected before verification (no stale fallback); validates session set, close/availability, batch provenance and finite OHLCV. No forward-fill. SHA256 snapshot binds selected rows, batches, capture timestamps and declared plan. Returns warmup nulls and versioned descriptive SMA 5/20/25/50/60/200, disparity (100=equal), EMA12/26, Wilder RSI14/ATR14, RAW price returns 1/5/20/60/120. No total return claim; no actual time-series inference, strategy or orders. Explicit synthetic fixtures use fabricated sessions including weekends, not verified exchange calendar. Existing feature seam NativeFeatureProvider computes SMA5/20, return and nonannualized realized volatility; this bridge is research-only and not a drop-in replacement; production integration requires parity, explicit units and independent authorization. Current legacy snapshot behavior unchanged; strict consumer refuses unverified latest. Capture timestamp is collector time not original public time; retrospective reconstruction not evidence of live availability. Caller evidence refs not proof, no calendar/adjustment authority; no persistent raw archive, source rights, real backtest or exact-decimal quote parity. Existing Treasury three-year pilot remains historical and temporary. Known limitations: floating arithmetic, unbounded concurrent DB changes (caller must use stable read transaction), date range coverage is only declared session set; raw hash from existing ingest not independently reverified; price corrections and action-free attestation need independent checks. No provider calls, live deploy, new schedule or paid infrastructure.
