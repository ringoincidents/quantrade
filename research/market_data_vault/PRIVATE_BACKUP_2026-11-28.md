# Private raw + index backup v1 — research-only
Local POSIX trusted filesystem. Reuses existing SQLite vault, not a second provider. Raw authorized CSV files must be separately supplied as SHA256.csv in an owner-only directory outside any Git working tree. pack(index_path,raw_dir,new_destination,rights_confirmed=True) takes a SQLite consistent backup, copies raw originals and verifies each indexed normalized observation against parsed bytes and matching source batch; manifest last, fsync files/directories, no overwrite. Hash and parse the same bytes during normal ingest to remove separate-read mismatch. verify(package,expected_manifest_sha256) checks pinned manifest, exact file set, raw and index hashes, SQLite integrity, normalized rows and counts. restore(package,new_destination,expected_manifest_sha256,rights_confirmed=True) verifies source and destination, preserves original capture and revision metadata via index backup. Store returned manifest hash independently in trusted private records. Failure leaves a newly created incomplete directory; never use as completed backup without verify, no automatic deletion. Restore refuses existing destination. Not reconstruction from raw alone; SQLite snapshot is needed to preserve original verified flags and capture times. Bounded local size; no encryption, independent access control, authenticated manifests, remote off-site backup, source rights audit, storage provisioning or production deployment. Caller controls exclusive filesystem and source DB access; source schema trusted. No hostile filesystem or concurrent modification guarantees. Synthetic tests only. Existing Treasury-specific XML archive remains separate; no raw market data obtained or committed.
