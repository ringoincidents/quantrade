# QuanTrade decision review manual v0.1 (candidate)
Scope: research/development governance. Reuses canonical ReviewGate, does not modify current production routing or Founder authority. D0 routine doc/UI/local bug; D1 existing module extension/tests: own review + ordinary commit/test, no review memo or external call. D2 material new hypothesis/backtest design/algorithm: one independent blinded reviewer, focused review record, empirical verification before adoption. D3 strategy adoption/security/core architecture/production/capital/privacy/cost/irreversible change: two independent reviewers, Founder approval before execution/promotion. Any high-impact flag, unknown scope or unresolved material objection escalates D3; no splitting high-impact decisions to avoid review. D3 does not forbid safe reversible offline research; forbids treating it as approved. Existing independent human/security/financial gates not replaced by models. Classifications are explicit candidate policy, not statistical scores. Reviewers see frozen allowed materials independently; no private data, credentials, unauthorized source content. Keep findings, reproducible evidence and dissent, no voting truth into existence. D0/D1 use normal commits/tests, no extra bureaucracy. D2/D3 record code/input hash, reviewer identity/version, actual calls, costs, findings and disposition. Reuse prior review only for unchanged scope/evidence/artifact; material changes require a fresh review. Budget: zero live calls until Founder approves providers, disclosure scope and per-run/monthly hard caps. Call-plan prototype only; supplied booleans are declarations, no budget reservation, API invocation, identity verification or authority. Missing budget/permissions/reviewer -> blocked, not downgraded or pass; continue independent safe work. Measure cost, latency and verified incremental findings on seeded defects before expanding. No new subscriptions, deployment or production change. Tests synthetic only.
