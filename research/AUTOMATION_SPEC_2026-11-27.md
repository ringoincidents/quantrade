Store append-only raw artifacts (lawful storage scope), SHA256, retrieval time, provider ID, as_of, available_at, effective_at, original unit/currency, schema version, license/retention. Separate normalized observations from raw evidence, features and derived values. Unknown first availability quarantined for historical tests. As-of query selects records known before cutoff, never latest restatement retroactively. Missing/invalid/stale/conflicting observations must return reason codes, not silently impute. Session timezone and adjusted vs raw semantics explicit; USD/KRW conversion at a consistent timestamp. No private or licensed raw files in public Git.

Proposed physical implementation after PC access: existing SQLite P0 metadata + private Parquet raw/normalized datasets queried by DuckDB when volume warrants; backup and restore test before relying on permanent store. Choose provider on coverage/rights/accuracy/price/latency, not marketing. Official SEC/OpenDART are initial candidates; no claim of free comprehensive historical quotes, constituent data or analyst consensus. Respect rate limits and source terms. Reuse existing scheduled infrastructure only after explicit approval.

## 2. Calculator registry
Every output: metric_id, value, unit, instrument_id, period_end, known_at, input_refs, calc_version, quality flags, freshness, null reason. Pure deterministic functions; decimal money where necessary, reproducible floats for returns. No LLM arithmetic as authority.

### Technical and market
- SMA N (20/25/50/60/200): mean of last N valid session closes. EMA N: alpha=2/(N+1), seed SMA; version seed. Disparity=100*close/SMA; drawdown=close/running peak-1; historical peak definition/warmup explicit. RSI14 Wilder default, retain simple average RSI as separately versioned historical metric; define zero gain/loss handling. MACD EMA12-26, signal EMA9, histogram; Bollinger SMA20 ±2 population std, width; ATR14 Wilder true range=max(high-low,abs(high-prevclose),abs(low-prevclose)); volume ratio=volume/prior 20-session average excluding current; CMF20 money flow multiplier times volume/sum volume, zero-range rule. Return 1/5/20/60/120 sessions; realized vol=std daily returns*sqrt(252). Support/resistance heuristic versioned (rolling pivots/volume zones, not guarantees).
- Market breadth, KOSPI/KOSDAQ/SPY/QQQ/SOXX relative strength and 20-day trend, foreign flows if permitted, credit spreads, 10y/2y, policy upper bound, 2y minus policy, VIX, CPI/PCE/jobs/GDP, USDKRW, oil/gold, Korea exports. Preserve existing market calendar/11-item checklist as separate versioned rule set; don't infer missing conditions. Baa vs HY distinct. Compare release actual vs consensus only with timestamped consensus; label source and stale data. No prediction activation.

### Financial
- Revenue/operating profit/net income YoY using same fiscal period, margins, quarterly vs cumulative conversion, TTM=sum latest four standalone quarters. CFS preferred with NCI/attribution, no mix with OFS. EPS diluted, shares split-adjusted. CFO, capex cash purchases tangible+intangible when relevant; FCF_simple=CFO-capex; separate lease principal, SBC economic cost, normalized recurrent acquisition expense, nonrecurring legal/tax gains, financial income, NCI and financing flows; cash reconciliation. Do not deduct same cost twice. R&D, receivable/inventory days, working capital and cash conversion, debt maturity, covenant where available.
- ROIC=NOPAT/average invested capital; specify invested capital and tax definitions incl lease/goodwill, exclude invalid denominators. ROE=attributable NI/avg attributable equity. ROIC-WACC; ROE-Ke for financials; net debt/EBITDA, interest coverage, cash/receivables, FCF conversion, growth, P/E, P/B, EV/EBITDA, FCF yield; TTM and historical three-year metrics. Loss or negative denominator => unavailable, not cheap. Use model-specific financial exceptions.
- DCF FCFF: EBIT*(1-tax)+D&A-capex-change NWC; discount WACC; equity bridge enterprise value + nonoperating assets - net debt and other senior/NCI claims (no double count), divide diluted shares. FCFE=CFO-capex+net borrowing, adjust classification/NCI/leases and SBC coherently; discount Ke, no subtract debt again. Historical chat 'normalized CF' models must be classified/rebuilt, not silently treated as exact FCFF/FCFE. Two-stage 10y flows F_t=F0*(1+g1)^min(t,5)*(1+g2)^max(t-5,0); terminal F10*(1+gT)/(r-gT), r>gT; PV, equity bridge, ADR conversion, sensitivity and reverse DCF solve implied growth. Scenario assumptions manually evidenced (not fixed by LLM); terminal share of value, downside cases, confidence. Safety margin=1-P/V, upside=V/P-1, remaining fall to entry=max(0,1-entry/P). Target P=V*(1-m); never use optimistic value as base without explicit label.
- Financial institutions: justified P/B=(normalized ROE-g)/(Ke-g), residual income B0+PV((ROE-Ke)*opening equity), CET1, risk-weighted assets, NIM, credit cost, capital return constraints. Insurer separate solvency/regulatory capital and earnings definitions.
- Cyclical companies: multi-year normalized EPS/CF, downturn scenario, commodity/FX sensitivities; retail brand inventories, recurring rent/lease obligations. EPS-multiple model explicitly separate from DCF. Rental/finance lease: cohort cash flows, origination cost, funding, default and prepayment, not naive CFO.
- Biotech rNPV: probability-weighted staged development costs and milestone/royalty schedules, clinical/regulatory/launch probabilities conditional; finite patent life, competition, FX, tax, overhead and net cash; no contract headline maximum as PV; no royalties before milestone eligibility, no duplicated income; missing terms = scenario or blocked.
- ETF: holdings weighted earnings yield, valuation methodology, tracking difference, fees, distribution-adjusted total return, factor/sector/country concentrations; P/E scenarios not intrinsic DCF. Gold/short bonds: total return incl interest, FX, fees, tax; no assumed hedge. KRW return=(1+local_return)*(1+FX_return)-1, FX quote explicitly KRW per unit local currency.

### Portfolio, performance and execution constraints
- NAV=sum mark-to-market positions+cash+settlement receivables-payables (avoid reservation double counting); mark price and FX cutoff; cash by currency, available vs reserved, settlement date. Equity weight, top issuer/sector/currency exposures; look-through direct + fund_weight*underlying_weight, normalize share classes to issuer, derivative delta where supported; show unallocated/uncovered and residual rather than pretend full coverage. ETFs overlap does not imply same net exposure with options. Geographic listing vs revenue/FX exposure separate.
- Position risk limits configurable; whole-share integer, budget=min(free cash after existing reservations - minimum reserve, position and sleeve capacity, currency purchasing power); floor by all-in cost incl fees/FX/spread. No order if negative or data not known. Candidate quantity suggestion only; pending orders remain pending until confirmed. Stress shocks and covariance historical windows labeled, KRW returns incl FX; no correlation claim from single event.
- Time-weighted and money-weighted return (XIRR), realized/unrealized incl fees and distributions, NAV benchmark matched currency and flows, max drawdown, CAGR, vol, Sharpe with cash proxy, turnover, tax/fee scenarios. A distribution is not extra return. Record cash deposits and withdrawals separately.
- Income transition: annual net cash target / assumed net sustainable yield, sensitivity to inflation and taxes, dividend cuts; compare accumulation with income ETF strategies using matched start date total return. No yield guarantee.

## 3. Opportunity pipeline & decision record
G0 data integrity + rights + as-of coverage; G1 investable universe and liquidity; G2 financial quality; G3 valuation; G4 technical/catalyst; G5 existing position/benchmark alternative; G6 portfolio/risk capacity; G7 decision outcome evaluation. Financial exceptions and speculative assets separate; no forced daily picks. Daily all-universe broad screen only once approved data coverage; until then explicitly label partial universe. Default research filters: KR market cap>=100bn KRW, US>=300m USD, positive normalized earnings, 3y cumulative FCF>0, 3y ROIC>=10% or >WACC, net debt/EBITDA<=3, interest coverage>=3, FCF yield>=5%; thresholds hypotheses, not mandatory for all sectors. Filter failures recorded. Liquidity threshold to calibrate, no invented value.

Score weights 25/20/20/15/10/10; each subscore has raw data and mapping version, manual qualitative review flagged; missing mandatory input => unscored, never assume zero or fabricate. Thresholds >=85 buy review; 75–84 conditional review; 65–74 observe; 50–64 no new buy; <50 thesis review. No score authorizes trades or proves edge. Hard stops: unknown data, material accounting/liquidity risk, invalid thesis, unverified valuation, insufficient cash/order conflict/limit breach. Entry bands 15/20/30% hypotheses. Trade class long-term vs tactical, separate exit rules (valuation/position/fundamental vs defined time/stop/target), no buy on price alone. Track alternative candidate and reason for inaction.

Immutable decision event fields: decision_id, strategy/version, as_of/market session, instrument, thesis and invalidation, horizon, price/valuation snapshot & evidence IDs, score breakdown, proposed action/qty, cash/limits, alternatives, actual human approval, status (research/rejected/pending/filled/cancelled), execution refs (private), supersedes, unknowns. Public research no personal account values. Outcomes at 1/5/20/60/120 sessions, total return incl distributions and corporate actions, currency benchmark excess, MAE/MFE, max drawdown, rejected/held cases; preserve missed/unfilled opportunities and avoid survivorship. Capture reference prices only when known; record old chat calls as retrospective historical notes, not simulated real decisions.

## 4. Scheduler, incremental workload and report contract
- EOD per exchange: pull changed bars/corporate actions, update rolling features once, reprice saved valuation snapshots, update exposure/risk/targets. Separate US holiday/half-day and KR session; no stale price called today. Release calendar & event-driven filings: fetch only unseen accession/receipt; diff and invalidate impacted models; queue human review. Weekly universe refresh and research shortlist; monthly/quarterly portfolio model review; schedule only after approval. Data staleness policies per series/filing, not arbitrary daily full DCF recompute.
- Evidence cache keyed by provider + canonical instrument/filing/event + content hash; compute key = input hashes + calc version + configuration + as_of. Recompute only dependency changes; batch requests, provider quotas, dedupe, retries/backoff, error telemetry. Store LLM extraction separately with source span and confidence; cache by document/model/prompt hash. Trigger LLM only material deltas, ambiguous mappings, valuation assumptions and decision explanations. Never send private holdings to public repos; budget token and provider calls, log per-run actual counts/cost. No claimed cost savings until baseline measured.
- Daily report (numeric-first, no dashboard required): time/as-of and freshness; macro actuals/changes and risk; account cash/order status; holdings changes; top passed candidates ranked with base valuation, margin, latest price, technical metrics, catalyst, risk, whole-share cost/weight; rejected/blocked reason; recommended actions requiring approval; research queue and evidence links; no unnecessary repeated long research. Report-only mode first.
- Monitor existing 24 assets plus newly researched candidates; watchlist and targets versioned; merge with existing watch automation only by separately approved migration. Do not send duplicate alerts; threshold crossing, thesis changes, data errors separately logged.

## 5. Experimental protocol and implementation order
P0 (existing #137/#138): resume after PC access; confirm CI, licensed input, PIT, adjustment and backup/restore. P1 financial adapters + canonical normalization + feature calculators; synthetic golden fixtures for units, split, amendments, standalone quarter, FX, nonrecurring items, lease, ADR, bad denominators and missing values. P2 valuation & screening report-only; hand-calculate examples, compare with independent filings, preserve range and error flags. P3 private portfolio and journal, integer quantity/settlement/duplicate-order tests; no broker. P4 replay past research with frozen snapshots; full-universe PIT/delistings/constituents; matched-risk baselines and ablation, walk-forward/OOS, crisis holdout, transaction costs/cash yield/tax, KRW total returns, confidence intervals. P5 scheduled read-only reporting after explicit approval; monitor data completeness and cost. P6 only after separate investment committee/risk decision and approval; manual order remains default.

Acceptance tests: deterministic same input => same output, input hash & source traceable, no future data, corrected filing does not leak, split/dividend not double counted, provider conflict quarantined, incomplete coverage printed, thresholds versioned, unknown value blocks trade, actual fill required before balance changes, no duplicate alerts, incremental run matches full rebuild, restore test, no private data in public artifacts. Existing v3.2 alpha/prediction disablement remains; no production adoption authorized by this spec.
